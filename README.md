# YouTube Seven Channels

نظام مركزي لإنتاج وإدارة محتوى YouTube Shorts لسبع قنوات مستقلة، وفق الدليل التشغيلي المعتمد.

## القنوات
1. **كواليس المال (Smart Money):** الثقافة المالية والاقتصاد السلوكي.
2. **إكسير (Elixir):** العلوم والكيمياء والفيزياء.
3. **متاهة العقل (Mind Maze):** الألغاز الذهنية والخدع البصرية.
4. **غريزة (Instinct):** الحياة البرية وسلوك الحيوانات.
5. **بصمة مجهولة (Unknown Trace):** القضايا والألغاز الحقيقية الموثقة.
6. **سر الصناعة (Inside Industry):** التصنيع والعمليات الصناعية.
7. **تاريخ بلا رتوش (Unfiltered History):** الوقائع التاريخية الغريبة الموثقة.

## خط الإنتاج المستهدف
إعداد القناة ← بحث المصادر والتحقق ← منع تكرار الأفكار ← كتابة النص ← مخطط المشاهد والأصول ← التعليق الصوتي ← المونتاج ← فحص الجودة ← النشر ← تحليل الأداء.

## المواصفات الافتراضية
- مدة الفيديو: 45–58 ثانية.
- تغيير المشهد: كل 2.2–2.8 ثانية.
- الترجمة: 1–3 كلمات في اللقطة.
- مستويات الصوت المرجعية: التعليق 0 dB، المؤثرات -18 dB، الموسيقى -24 dB.

## ضوابط أساسية
- إعدادات وهوية وأرشيف مستقل لكل قناة.
- فحص المصادر والحقوق والأصالة قبل اعتماد أي فيديو.
- منع تكرار الفكرة أو رفع الفيديو نفسه أكثر من مرة.
- النشر العام غير مفعّل في مرحلة التأسيس. لا يوجد رفع تلقائي قبل إعداد ربط القنوات واختبار المصادقة والنشر.
- تغيير القص أو LUT أو البيانات الوصفية لا يجعل المحتوى المكرر أصليًا ولا يحل حقوق الاستخدام.

## فحص الإعدادات
يتطلب Python 3.11+:

```bash
python scripts/validate_config.py
```

هذا الفحص محلي ولا يتصل بخدمات خارجية.

## حالة التنفيذ
تم إنشاء إعدادات القنوات السبع، إعدادات خط الإنتاج، قواعد حفظ الأسرار والوسائط، سجلّات الأفكار والفيديوهات المنشورة، وفاحص اتساق الإعدادات. مراحل البحث والتوليد والصوت والمونتاج والنشر ستُبنى فوق هذه الطبقة بعد تحديد خدمات الصوت والذكاء الاصطناعي وربط قنوات YouTube.
