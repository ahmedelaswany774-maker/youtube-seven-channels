# مصنع كومبو سيتي للفيديوهات القصيرة

مشروع مستقل داخل مستودع `youtube-seven-channels`، ولا يغيّر ملفات نظام القنوات السبع.

## ما الذي يفعله؟

يختار فكرة واحدة غير مستخدمة من `ideas.csv`، ثم:
1. يكتب سيناريو مصريًا قصيرًا بصيغة JSON عبر Gemini.
2. ينشئ أربع صور للمشاهد عبر Pollinations، مع بديل رسومي محلي إذا تعذّر مزود الصور.
3. ينشئ تعليقًا صوتيًا عربيًا عبر Edge-TTS بصوت `ar-EG-SalmaNeural`.
4. ينشئ ترجمة SRT ويحرقها على الفيديو.
5. يركّب فيديو عمودي 1080×1920، 30fps، ومدته المستهدفة 45 ثانية، مع حركة Ken Burns.
6. يفحص وجود مساري الفيديو والصوت والأبعاد والمدة قبل اعتبار الفكرة مستخدمة.
7. يحفظ MP4 وبياناته في `output/` ويرفع Artifact ويعمل commit للنتيجة.

## الإعداد

1. افتح المستودع ثم **Settings → Secrets and variables → Actions → New repository secret**.
2. أضف السر باسم `GEMINI_API_KEY` وضع مفتاح Gemini من Google AI Studio.
3. لا تضع المفتاح داخل أي ملف في المستودع.
4. افتح **Actions → Kombo City Factory → Run workflow** للتجربة الأولى.

## الجدولة

ملف workflow يفحص توقيت القاهرة الساعة 05:00 و06:00 UTC، ويكمل التشغيل فقط عندما تكون الساعة المحلية 08:00 في القاهرة؛ وهذا يراعي التوقيت الصيفي والشتوي. التشغيل اليدوي لا ينتظر شرط الساعة.

## الملفات

- `ideas.csv`: بنك 30 فكرة.
- `used.txt`: سجل IDs التي اكتمل إنتاجها بنجاح.
- `main.py`: خط الإنتاج والتحقق.
- `prompts/system_prompt.txt`: تعليمات توليد السيناريو والصور.
- `output/`: الفيديوهات والبيانات المصاحبة.
- `assets/music.mp3`: اختياري؛ أضف موسيقى تملك حق استخدامها فقط، وسيتم مزجها بمستوى 10%.

## متطلبات مجانية وحدودها

- لا توجد مكتبات أو خدمات مدفوعة مطلوبة في الكود.
- Gemini المجاني يخضع لحصص وحدود استخدام تتغير حسب الحساب والنموذج.
- Pollinations خدمة خارجية وقد تتعطل أو تضع حدودًا؛ عند فشلها يستخدم المشروع صورًا محلية احتياطية.
- Edge-TTS يعتمد على خدمة Microsoft وقد تتغير إتاحته أو سياساته؛ لا يوجد ضمان تشغيل غير محدود.
- GitHub Actions المجاني له حدود دقائق وتخزين حسب نوع الحساب والمستودع.
- الموسيقى غير مرفقة افتراضيًا لتجنب استخدام مادة غير مرخصة.

## ملاحظات مهمة

- لا يتم رفع الفيديو إلى YouTube تلقائيًا؛ هذا المشروع ينشئ الفيديو ويحفظه في GitHub Artifacts و`output/`.
- لا يعلّم الفكرة كمستخدمة إلا بعد نجاح فحص MP4.
- لا يعيد استخدام فكرة مسجلة في `used.txt`.
- إذا فشل Gemini أو الصوت أو FFmpeg، يفشل الـ workflow بوضوح ولا يستهلك الفكرة.
- مدة الصوت تُضبط لتناسب 45 ثانية ضمن نطاق سرعة محافظ؛ إذا كان الفرق كبيرًا يتوقف بدل قطع الكلام.
